G1 ACQ Plus — версия 2.0.0
Windows 10/11 x64 Intel/AMD и macOS Apple Silicon (M1 и новее)
Windows: LDPlayer. Mac: MuMu.
Спонсор скрипта: https://animeyume.online

Это Android-адаптация опубликованного каталога Dgkncn/g1-acq-plus.
Оригинальный sgmodule для iOS/Shadowrocket напрямую в Android не запускается.
Каталог зафиксирован на коммите c9c91e8e4e315edf62d949e0fe33e30502559218.
Включены 124 идентификатора из каталога и 11 дополнительных кандидатов,
упомянутых в коде проекта. Внутренние ключи хранилища не считаются товарами.
Чужие offer/purchase tokens из каталога не включены и не используются.

ЗАПУСК
Установщики самостоятельные: исходники и BillingClient DEX встроены.
Windows: Windows-OneClick.ps1 либо распакованный install/windows.ps1.
Mac: Mac-OneClick.command либо распакованный install/mac.zsh.
Для распространения используйте новые команды из COMMANDS.txt, когда он есть.

ПОДГОТОВКА
1. Загружается uv 0.13.10 с проверкой SHA256 официального релиза Astral.
2. uv устанавливает отдельный управляемый Python 3.13 в папке программы.
   Системный установщик Python EXE/PKG не используется. PATH и Windows Registry
   не меняются (--no-bin --no-registry).
3. Фактический путь Python запрашивается у uv и проверяется как существующий
   файл. После создания venv её python.exe/python проверяется ещё раз.
   Отсутствующий путь не выполняется. Это устраняет прежнюю схему ошибки,
   когда стандартный установщик завершился, а ожидаемый python313/python.exe
   не появился по заданному адресу.
4. Зависимости устанавливаются по requirements.lock с проверкой хешей колёс.
5. Если LDPlayer в Windows не найден, в браузере открывается личная ссылка
   автора https://leap.ldplayer.gg/T4WsicN6b. Установите LDPlayer с этой страницы
   и вернитесь в скрипт. Ссылка не подменяется прямой непартнёрской загрузкой;
   партнёрский номер в проверенном перенаправлении — 64774869.
   На Mac при отсутствии MuMu загружается DMG через
   официальный Mac-endpoint с параметрами кампании из исходной ссылки.
6. Выбирается одно устройство эмулятора, включается его штатный Android root,
   выполняется перезапуск и проверка su -> uid=0. Права root macOS не включаются.
   В LDPlayer соответствие локального ADB-порта выбранному индексу проверяется
   временным маркером через официальный ldconsole до выполнения root-команд.
7. Войти в Google Play, установить Google One и завершить его первоначальную
   настройку нужно самостоятельно. Это выполняется в окне эмулятора.
8. После успешного получения непустого каталога терминал показывает крупный
   баннер «СКРИПТ СПОНСИРОВАН САЙТОМ» и animeyume.online. Баннер подстраивается
   под размер окна. Затем в браузере один раз за запуск открывается сайт
   спонсора. Нажмите Enter в терминале для перехода к меню предложений.
   При ошибке подготовки, --doctor и --scan-only сайт не открывается.
   Обновление каталога не открывает сайт повторно. Никаких параметров аккаунта
   или идентификаторов в адрес сайта спонсора скрипт не добавляет.

РАБОТА С КАТАЛОГОМ
- Запрашиваются только опубликованные идентификаторы, пакетами до 20 штук.
- В меню попадают предложения, фактически возвращённые Google Play для аккаунта.
- Цены и периоды читаются из актуального ответа Google Play.
- Авторские обещания 15/18 месяцев не считаются подтверждённой доступностью.
- Перед открытием оформления выбранный вариант запрашивается заново.
- Если он пропал, другой тариф автоматически не подставляется.
- Скрипт только открывает стандартное окно Google Play. Окончательные условия
  нужно проверить и подписку подтвердить вручную в эмуляторе.
- Прежний режим продления/суммирования подписок не переносился: новый проект
  работает с опубликованным каталогом и обычным Google Play checkout.

МЕНЮ
Номер — перепроверить выбранное предложение.
/текст — поиск по названию или идентификатору. Одна / сбрасывает поиск.
n/p — следующая/предыдущая страница.
a — показать/скрыть базовые тарифы без акции.
r — обновить каталог.
q — выйти.

ФАЙЛЫ ПРОГРАММЫ
Windows: %LOCALAPPDATA%\G1AcqPlus
Повторный запуск: ярлык G1 ACQ Plus или Start-G1.cmd в этой папке.
Mac: ~/Library/Application Support/G1AcqPlus
Повторный запуск: Start-G1.command в этой папке.
Диагностика: --doctor; актуальные ответы: live-offers.json; ошибки: last-error.log.
Данные аккаунта, цены и ошибки не отправляются разработчику; счётчика запусков нет.

ПАРАМЕТРЫ
Windows install/windows.ps1: -Doctor, -RuntimeOnly, -Manager <путь>, -Instance N.
По умолчанию используется LDPlayer; -Emulator mumu выбирает прежний адаптер MuMu.
Mac install/mac.zsh передаёт параметры в программу, например --doctor или
--instance N. Для проверки только установки среды задайте G1_RUNTIME_ONLY=1.
Корень Mac-установки можно задать переменной G1_INSTALL_DIR.

ОГРАНИЧЕНИЯ
Для отдельной среды потребуется 2 ГиБ. Свободное место для LDPlayer проверяйте
по требованиям его установщика; для новой установки MuMu — хотя бы 8 ГиБ.
Если выбранный эмулятор уже установлен, используется он. Windows ARM и Intel Mac
не поддержаны. Нативной Mac-версии LDPlayer в этой сборке нет.
Часть версий MuMu может требовать вручную разрешить локальный ADB/root в окне
устройства. Проверка доступа обязательна до загрузки каталога.
Начисления определяет партнёрская система. Наличие ссылки не подтверждает
оплату за простое скачивание, доступность отдельного оффера на эмулятор
или применимость оплаты к Mac. Проверьте условия именно своего оффера.
Вывод об оплате LDPlayer только по публичному FAQ не делается: в кабинете
могут быть доступны только игровые офферы. Искусственные установки/повторные
запуски для начисления комиссии скрипт не выполняет.

ПРОВЕРЕНО
- Реальная чистая установка Python 3.13.18 и всех зависимостей на Mac.
- Повторный запуск этой среды; путь содержит пробелы и кириллицу.
- Синтаксис PowerShell и 4 проверки отсутствующего/неполного Python runtime.
- 27 Python-тестов каталога, выбора устройства, root, оформления и спонсорского
  экрана; сайт не запускался при тестировании — вызов браузера был заменён.
- 10 офлайн-проверок JS Billing bridge с имитацией Java API.
Офлайн-тесты не являются проверкой реального оформления подписки.
Полная установка на Windows и полный цикл Google One в LDPlayer/MuMu в этой среде
не выполнялись: работающего Android-эмулятора сейчас здесь нет.
